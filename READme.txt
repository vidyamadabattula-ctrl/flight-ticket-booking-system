# Flight Ticket Booking System

A console-based Flight Ticket Booking System developed in C to manage flight reservations using fundamental Data Structures and programming concepts.

## Overview

The Flight Ticket Booking System allows users to search for flights using either the **destination city** or **flight number**, book tickets, view booking details, and cancel reservations.

The project focuses on applying C programming fundamentals and Data Structures to a practical ticket booking application.

## Features

- Search flights by destination city
- Search flights by flight number
- View available flights
- Book flight tickets
- View booking details
- Cancel booked tickets
- Menu-driven console interface
- Input validation for booking operations

## Technologies Used

- C
- Data Structures
- Arrays
- Structures
- Functions
- Loops
- Conditional Statements
- String Handling

## Data Structures Used

### Structures

Structures are used to store related flight and passenger information such as:

- Flight number
- Source
- Destination
- Passenger details
- Ticket information

### Arrays

Arrays are used to store and manage multiple flights and booking records.

## How It Works

1. The user selects an operation from the menu.
2. Flights can be searched using either:
   - Destination city
   - Flight number
3. The user selects a flight and provides the required passenger details.
4. The system stores the booking information.
5. Users can view or cancel their bookings through the menu.
